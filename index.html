CodeLensAI

Laravel Claude API PostgreSQL Docker

リポジトリの“記憶”を育てる Repository Intelligence プラットフォーム。 GitHub URL を貼ると、AI が重要ファイルを読み、品質・セキュリティ・保守性を評価し、 レビューを一冊の“本”として書架に残す。スコアは結論じゃなく、リポジトリが書き続ける物語の一行。

  • Repository Core / DNA / Archive を設計し、レビューを“記憶”として蓄積
  • 同一コミットは同一スコアを返す決定論的評価
  • 実リポジトリ RewardMe を5回再レビューし、Overall 49 → 66（+17）を実証

RewardMe

Ruby on Rails Hotwire Stimulus PostgreSQL

タスクを“体験”に変えるゲーミフィケーション Todo アプリ。 EXP・ガチャ・キャラ育成・ミニゲーム・マイルームで、毎日のルーティンが続けたくなる仕掛けに。

  • Hotwire（Turbo / Stimulus）でゲームのような演出を SPA 風に実装
  • completed_count を単一の真実として設計し、整合性を担保
  • 毎日継続したくなる UX を軸に、企画から作り込み

FrameLens

C++ OpenGL WebAssembly WebGL2 Emscripten

C++/OpenGL で実装した 3D フレーム解析ツール。 2×4 フレームの手続き生成・リアルタイム3D可視化・部材ハイライト・寸法表示・拾い出し CSV 出力を実装。 さらに Emscripten で WebAssembly / WebGL2 に移植し、ブラウザでそのまま動く。

  • OpenGL によるリアルタイム3D描画と Ray Picking
  • Procedural Generation による2×4フレーム自動生成
  • C++ → WebAssembly → WebGL2 でネイティブアプリをブラウザへ
